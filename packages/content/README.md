# `@zcashreveal/content`

The typed content package the Record renders from. Zod schemas for every claim
type, JSON seeds transcribed from the research dossiers, a validator that fails
the build on a missing source or a quarantined claim that has leaked, and typed
loaders with claim-id permalinks.

It contains no rendering and no new research. Everything in `data/` is a
transcription of `docs/2.0/RESEARCH-2026-08-DOSSIER.md` and
`docs/2.0/research/01..04`. Where the dossier says `low`, the seed says `low`;
where the dossier says a thing is unverified, the seed puts it in
`data/unverified.json` and nowhere else.

## Layout

```
src/schema.ts        zod schemas + the id conventions + labeller precedence
src/loaders.ts       typed, memoised readers over data/
data/*.json          the seeds
scripts/validate.ts  the gate; runs in CI
scripts/build-sources.mjs    regenerates sources.json from the dossiers
scripts/check-provenance.mjs every source url must occur in the corpus
scripts/resolve-refs.mjs     rewrites url citations into source ids
test/                the assertion suites
```

## Commands

```bash
pnpm --filter @zcashreveal/content validate          # the gate: counts, refs, dates, quarantine
pnpm --filter @zcashreveal/content test              # vitest
pnpm --filter @zcashreveal/content typecheck
pnpm --filter @zcashreveal/content check:provenance  # no source was invented
```

## The id conventions

| Prefix | Meaning | Example | Page |
|---|---|---|---|
| `B1`..`B14` | Beware ledger entry | `B2` | `/beware` |
| `C1`..`C16` | Contradiction | `C10` | `/contradictions` |
| `T<ISO-date>[-n]` | Timeline event | `T2026-06-04-2` | `/timeline` |
| `N-<slug>` | Network entity | `N-cypherpunk-technologies` | `/network` |
| `N-edge-<slug>` | Network edge | `N-edge-winklevoss-capital-seeds-cypherpunk` | `/network` |
| `P-<slug>` | Catalogued phrase | `P-encrypted-bitcoin` | `/network` |
| `L-<address>` | Address label | `L-t3ev37Q2uL1sfTsiJQJiWJoFzQpDhmnUwYo` | `/flows` |
| `K-<slug>` | Reconstructed case | `K-2026-01-02` | `/flows` |
| `U-<slug>` | Quarantined claim | `U-korean-exchange-dominance` | `/sources` |
| `S-<slug>` | Source | `S-zcash-improvement-proposals-zip-271-...` | `/sources` |

`permalink(id)` returns the site-relative location; `permalink(id, { base })`
returns the absolute canonical URL a citation popover needs.

## Three rules the code enforces rather than documents

**Every claim carries provenance.** `sources` has a `min(1)` on it, so a claim
with nothing behind it cannot parse. The validator additionally resolves every
reference against `sources.json` and rejects a `lastVerified` in the future.

**Nothing invents a source.** `sources.json` is generated by
`scripts/build-sources.mjs` from the union of every URL in the four dossiers, 328
of them de-duplicated. `check-provenance.mjs` asserts every URL in the file
occurs in the corpus. Transcription cites the URL printed on the row it came
from, and `resolve-refs.mjs` rewrites those URLs into ids, failing on any URL the
corpus does not contain. A citation from outside the research cannot survive the
pipeline.

**The quarantine cannot leak.** The validator takes every `claim` string in
`unverified.json` and asserts it appears in no other data file. An unverified
premise cannot be promoted to fact by editing one file, because the check reads
all of them.

## Dates

Dates the corpus states to the day are ISO. Dates it states loosely stay verbatim
strings: `discovered: "pre-launch"`, `dateText: "Apr-Jun 2018"`. Timeline events
carry both, because a sort key and a fact are different things: `date` is the
earliest day consistent with the corpus and exists only to order the list, and
`datePrecision` is what stops it being read as a claim.

## Pools

`supplyBucketSchema` is `transparent | sprout | sapling | orchard | ironwood`.
That is deliberately not `Pool` from `@zcashreveal/types`, and since HANDOFF-06
the reason is no longer that the two unions differ in their shielded members -
they agree on all four. The difference is the fifth: transparent is not a pool
at all, but supply accounting needs all five on one axis, and admitting it to
`Pool` would let it reach a commitment tree and a nullifier set it cannot have.
